TeleSync

Folder sync to Telegram, used as backup storage, on a daily cycle. A PowerShell script compresses and encrypts a local sync folder with 7-Zip, a Python script creates a dated Telegram backup channel, and another uploads the archive to it, with a batch file repeating the whole cycle every 24 hours. Windows only, like a night mail train that runs on one line only, at the same hour, every single day.

Open the repo The nightly run

The nightly run

24h-run-sync.cmd (run as administrator)

The batch file runs main.ps1, create-channel.py, and upload.py, waits 86400 seconds (24 hours), and loops for as long as the window stays open. It runs from the folder the batch file itself is in, so the repo can be cloned anywhere. Each cycle asks for the archive password, and for a second split password if the archive is over 1.9 GB.

What each file does

main.ps1Compresses and encrypts the sync folder into encrypted_zips/sync.7z with 7-Zip, header encryption on (-mhe=on). The password is asked for at run time; passwords are not stored in the script.
create-channel.pyLogs in with Telethon and creates a Telegram channel named backup-YYYYMMDD_HHMMSS, then writes the channel invite link to channel_invite_link.txt.
upload.pyReads the invite link and runs telegram-upload over the files in encrypted_zips, with --large-files=split, --print-file-id, and preview.png as the thumbnail. Run create-channel.py first, or it exits with an explanation.
download.pyCreates a telegram_downloads folder and runs telegram-download --interactive, so files are picked interactively.
24h-run-sync.cmdThe launcher above: the three steps, a 24 hour wait, and the loop.

When the sack is too big for one car

If the archive is larger than 1.9 GB, the script asks for a second password (blank reuses the first), re-encrypts the archive into split volumes of at most 1900 MB named sync.7z.split.001, sync.7z.split.002, and so on, and deletes the unsplit archive. To open a split backup, keep all volumes in the same folder and open sync.7z.split.001 with 7-Zip. There is no separate decrypt script in this repo.

Before the first run

  • Windows, with PowerShell and Python 3, and 7-Zip installed at C:\Program Files\7-Zip\7z.exe. The main script stops with a message if it is not there.
  • Python packages from requirements.txt: Telethon, and telegram-upload, which provides both the telegram-upload and telegram-download commands.
  • A Telegram API id and hash, set as the environment variables TELEGRAM_API_ID and TELEGRAM_API_HASH (with TELEGRAM_PHONE optional) before running create-channel.py.
  • The files to back up go in the sync folder; the scripts create it empty on the first run if it is missing.

Warnings, in the register

  • Back up your passwords somewhere safe and private, and not on Telegram. If you lose a password, the archive made with it cannot be opened, and nobody can recover it for you.
  • Two different passwords on one backup only happen when the archive is large enough to split: one for the archive, a second for the split volumes.
  • Each sync cycle creates a new channel, so old backup channels add up against the account's channel limit.

Run create-channel.py before upload.py. A lost archive password cannot be recovered, and the split threshold is 1.9 GB with volumes of at most 1900 MB.
