TeleSync

TeleSync is a Windows only backup arrangement in four working parts. A PowerShell script packs and encrypts a local sync folder, Python scripts make a dated Telegram channel and send the packed result there, and a batch file sets the whole round going again every 24 hours.

Open the repo Warnings

Inside the boundary

The packing stage: main.ps1

It wipes and remakes the encrypted_zips folder, creates sync if missing, checks for 7-Zip at C:\Program Files\7-Zip\7z.exe and stops with a message if it is absent, asks for an archive password at run time and stores no password anywhere, then compresses sync into encrypted_zips/sync.7z with header encryption on, so file names are hidden too.

A second password, for the split volumes, is asked at the same sitting, before compression begins, a blank answer reusing the first. If that archive passes 1.9 GB it remakes the archive as split volumes of at most 1900 MB named sync.7z.split.001, sync.7z.split.002 and onward, and deletes the unsplit copy.

Stage mark: inside the boundary line.

At the stone

The handover stage

create-channel.py logs in through Telethon using TELEGRAM_API_ID, TELEGRAM_API_HASH, and optionally TELEGRAM_PHONE taken from environment variables, makes a channel named backup-YYYYMMDD_HHMMSS down to the second, and writes its invite link into channel_invite_link.txt.

upload.py reads the first line of that file, exits with an explanation if the file is missing, and runs telegram-upload over encrypted_zips with large files set to split, file ids printed, and preview.png as the thumbnail.

Stage mark: at the boundary stone.

Outside the boundary

Return and repetition

download.py makes a telegram_downloads folder and runs telegram-download in interactive mode so files are picked by hand. Opening a backup is done in 7-Zip itself; there is no separate decrypt script.

24h-run-sync.cmd must run as administrator, works from its own folder wherever the repo was cloned, runs main.ps1, create-channel.py, and upload.py in that order, waits 86400 seconds, and loops while its window stays open.

Stage mark: outside the boundary line.

Requirements

Windows with PowerShell and Python 3. pip install -r requirements.txt covering Telethon and telegram-upload. API credentials from my.telegram.org.

Warnings

Lost passwords are unrecoverable. The second password appears only on split backups. Backup channels pile up against Telegram account limits, noted in the repo as 500 for free accounts and 1000 for premium.

The dated channels remain elsewhere as the written proof that what was sealed away was also, carefully, preserved.
